# xSAR Mesh Communications and Arbitration

[← Back to the xSAR repository map](README.md)

**Status:** Planned

Distributed communications for sensor and control nodes where routing, contention and degraded operation must be handled explicitly.

Planned coverage includes:

- node discovery and capability exchange;
- routing and forwarding policy;
- bus, channel and message arbitration;
- bounded retries and congestion behaviour;
- partition, reconnection and recovery handling;
- deterministic priority for safety- or control-critical traffic;
- observable network state and fault reporting.
