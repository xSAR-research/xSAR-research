# xSAR Digital Signal Processing

[← Back to the xSAR repository map](README.md)

**Status:** Early development

Hardware and software digital signal processing for acquisition, filtering, spectral analysis and real-time interpretation.

Coverage includes:

- dedicated DSP hardware and accelerator-based processing;
- software DSP on Linux and embedded Rust targets;
- filtering, FFT and spectral-analysis pipelines;
- repeatable test vectors and calibration data;
- latency, throughput and resource-budget measurement;
- clear boundaries between acquisition, transformation and interpretation.
