# xSAR Terrain and Feature Matching

[← Back to the xSAR repository map](README.md)

**Status:** Planned

AI-assisted matching of observed terrain, topographic and thermal features against stored references for localisation, comparison and change detection.

Planned coverage includes:

- optical, thermal, LiDAR and elevation-derived features;
- cross-view and cross-sensor feature correspondence;
- terrain-relative localisation and map matching;
- confidence, ambiguity and false-match reporting;
- traceable datasets, calibration and ground truth;
- embedded and Linux inference paths where practical.
